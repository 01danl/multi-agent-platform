# Frontend

React 19 + TypeScript + Vite + Tailwind v4 SPA for the AI Agent Platform.

- Dev: `npm run dev` (proxies `/api` to the backend on :8100)
- Build: `npm run build` · Typecheck: `npx tsc -b` · Lint: `npm run lint`

Project docs live in the repository root: [../README.md](../README.md) and
[../docs/architecture](../docs/architecture).
